# Horizonte Entregas — primeira versão

Site responsivo inicial para lojas e entregadores de Horizonte–CE.

## Arquivos
- `index.html`: página inicial, cadastro, login, recuperação de senha e painel básico.
- `firestore.rules`: regras iniciais para proteger perfis de usuários.
- `INSTALACAO.md`: instruções para configurar o Firebase e publicar no GitHub Pages.

## Importante
Esta é a primeira versão funcional de autenticação e cadastro. Ainda não implementa distribuição de corridas, pagamentos, rastreamento, notificações push ou painel administrativo. Não anuncie a plataforma como pronta para operação até essas etapas e a revisão de segurança estarem concluídas.
